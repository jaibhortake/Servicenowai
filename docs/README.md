# Project Documentation

This folder holds design notes, architecture docs, implementation summaries, and captured artifacts that are not required at runtime.

- `architecture/`: system structure and abstraction notes
- `catalog/`: catalog retrieval, lexical index, and conditional field docs
- `frontend/`: older frontend setup notes
- `mcp/`: MCP architecture and ServiceNow graph-flow notes
- `provider/`: provider configuration docs
- `project/`: planning and delivery summaries
- `artifacts/`: captured sample responses and reference data
